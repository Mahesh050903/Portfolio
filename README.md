# 💼 Mahesh's Portfolio

This is my personal portfolio website built using **React.js**, **Vite**, **Tailwind CSS**, and **Framer Motion** to showcase my skills, projects, and experience.

## ✨ Features

- 📱 Responsive Design – Works perfectly on all devices.
- 🎨 Modern UI with smooth animations.
- 🌙 Dark Mode Support.
- ⚡ Fast and Optimized Performance.
- 🔍 SEO Friendly.

## 🛠 Tech Stack

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion

## 🚀 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Mahesh050903/Portfolio.git
```

### 2. Navigate to the project folder

```bash
cd Portfolio
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will run at:

```text
http://localhost:5173
```
